# Slay — гексова стратегія в браузері

Клон класичної гри Slay (Шон О'Коннор) без збірки й залежностей: п'ять
файлів звичайного JavaScript. Зроблено як пісочниця для експериментів
з правилами та штучним інтелектом.

## Запуск

Відкрити `index.html` подвійним кліком або через будь-який статичний сервер:

```bash
python -m http.server 5177
```

і зайти на <http://localhost:5177/>.

## На телефоні через React Host

Гру можна встановити в [React Host](https://github.com/mlfind18s/react-host): «Додати» →
`https://github.com/mlfind18s/slay`. Після встановлення вона працює без мережі.

- На вузькому екрані карта зверху, панель знизу (прокручується). Підказки при наведенні
  на сенсорних екранах вимкнені. Скасувати виділення — довге натискання на карті.
- Партія автоматично зберігається після кожної зміни (`slay.autosave` у localStorage) і
  продовжується при наступному відкритті. Ручні «Зберегти» / «Завантажити» працюють як раніше.

Новий випуск: підняти `version` у `package.json`, закомітити й надіслати тег `v<version>`
окремим пушем. Workflow `.github/workflows/release.yml` збере `react-host-app.zip`
(`node scripts/package.mjs`) і прикріпить його до release. Локально:

```bash
node scripts/package.mjs
```

`react-host/` — копія пакувальника з репозиторію React Host, оновлюється там командою
`node tools/vendor-pack.mjs <шлях>/react-host`.

## Правила (коротко)

- Карта — острів із гексів. Кожен гекс належить гравцеві.
- **Територія** — зв'язна група гексів одного кольору. Діяти може лише
  територія з 2+ гексів: вона має столицю (будинок) і скарбницю.
- **Дохід**: 1 монета за гекс за хід. Гекси з деревами й могилами доходу не дають.
- На старті кожна столиця отримує 10 монет (`RULES.startMoney`). У першому
  раунді доходу нема, тож усі роблять перший хід рівно з 10 (`incomeOnFirstRound`).
- **Юніти**: селянин (1, зелений), списник (2, синій), лицар (3, чорний),
  барон (4, червоний). Ціна 10/20/30/40, платня за хід 2/6/18/54. Два юніти на
  одному гексі об'єднуються (сума рівнів ≤ 4). Юніти, що ще не ходили,
  підстрибують; ті, що вже ходили, напівпрозорі.
- **Захоплення**: юніт може зайти на будь-який чужий гекс, суміжний із його
  територією, якщо його рівень **більший** за захист гекса. Захист = найбільша
  сила на самому гексі та на сусідніх гексах того ж власника
  (столиця 1, замок 2, юніт — його рівень).
- Кожен юніт ходить один раз за хід: після будь-якого переміщення, захоплення
  чи рубання дерева він до кінця ходу втомлений (напівпрозорий)
  (`moveTiresUnit`). Об'єднання двох юнітів не втомлює результат, якщо
  цільовий юніт ще не ходив (`mergeTiresUnit`). Щойно куплений юніт ходить з
  наступного ходу (`boughtUnitCanMove`), але купити його можна одразу на
  ворожий гекс, якщо рівень дозволяє. Купівля селянина на свого юніта
  підсилює його й не рахується за хід.
- Містам (столицям) і замкам можна давати назви: подвійний клік по гексу або
  кнопка «Назвати місто» для виділеної території. Назва зберігається на гексі
  (`hex.name`), показується на карті й у підказці та зникає, коли будівлю
  захоплено. З консолі: `Slay.setName('q,r', 'Назва')`.
- **Замок**: 15 монет, захист 2, не рухається.
- **Банкрутство**: якщо на початку ходу скарбниця йде в мінус — усі юніти
  території гинуть (могили), гроші = 0.
- Захоплення столиці знищує скарбницю. Розділена територія: частина зі
  столицею зберігає гроші, інші отримують нові столиці з нулем. Самотній
  гекс втрачає столицю, юніт на ньому гине.
- **Дерева**: могили стають деревами; сосна виростає поруч із двома соснами,
  пальма — на березі поруч із пальмою. Рубати дерева треба юнітами.
- Перемога: коли лише один гравець має територію з 2+ гексів.

## Керування

| Дія | Як |
|---|---|
| Виділити територію / юніт | клік по своєму гексу |
| Перемістити / захопити | клік по цілі (білі крапки — свої, червоні — ворожі) |
| Купити юніта | кнопки в панелі або клавіші `1`–`4`, потім клік по гексу |
| Замок | `C`, потім клік |
| Завершити хід | `Enter` або пробіл |
| Скасувати останню дію | `Z` / `Backspace` |
| Зняти виділення | `Esc` або права кнопка |
| Пауза AI / дограти AI миттєво | `P` / `F` |
| Нова гра | `N` |

Наведення миші показує підказку із захистом гекса та економікою території.

## Структура

```
index.html      розмітка, стилі, підключення скриптів
js/hex.js       гексова геометрія (осьові координати, сусіди, пікселі)
js/game.js      правила: клас Game, RULES, стан, дії, хід, збереження
js/ai.js        жадібний AI, AI.custom, AI.simulate
js/render.js    малювання карти на canvas
js/main.js      панель, ввід, цикл ходів AI, window.Slay
```

Логіка гри (`game.js`) не залежить від DOM — її можна ганяти в Node,
підклавши `globalThis.window = globalThis` перед `require`.

## Експерименти

Усе доступне в консолі браузера через `window.Slay`.

**Правила.** `Slay.RULES` — об'єкт із усіма числами (ціни, платня, сила
замку, шанси росту дерев тощо). Зміни застосовуються до нових ігор:

```js
Slay.RULES.unitWage = [0, 1, 4, 12, 36];
Slay.RULES.pineSpreadChance = 0.8;
Slay.newGame();
```

Або на одну гру: `Slay.newGame({ players: ['human','ai','ai'], seed: 42, rules: { castleCost: 10 } })`.

**Складність комп'ютера.** У списку гравців для кожного комп'ютера обирається
рівень: легкий, середній, важкий. З консолі:
`Slay.newGame({ players: ['human', 'ai:easy', 'ai:hard', 'ai:normal'] })`.
Параметри рівнів лежать в `Slay.AI.levels` і діють одразу:

| Параметр | Легкий | Середній | Важкий | Що робить |
|---|---|---|---|---|
| `noise` | 7 | 0 | 0 | випадковий шум в оцінці цілей |
| `maxUnitLevel` | 2 | 4 | 4 | вище не купує і не підсилює |
| `castles` | ні | так | так | чи будує замки |
| `idleChance` | 0.45 | 0 | 0 | шанс «проспати» хід (лише рубає дерева) |
| `bufferTurns` | 0 | 3 | 3 | скільки ходів мінусу дозволяє при купівлі |
| `buyToAttack` | так | так | так | купує юнітів одразу на ворожий гекс, підсилює для атаки |
| `defendCapital` | ні | ні | так | прикриває столицю, якщо сусід може її взяти |
| `bonusMoney` | 0 | 0 | 2 | фора: монет на територію за хід |

Середній — це чесний жадібний AI без випадковості. Важкий грає так само, але
отримує фору 2 монети на кожну територію щохода і прикриває столиці; у
дуелях 2 на 2 він виграє в середнього приблизно 4 партії з 5, легкий — 1 з 8.
`Slay.AI.levels.hard.bonusMoney = 0` робить важкий чесним (тоді він майже
рівний середньому), а `Slay.AI.levels.normal.noise = 1` трохи розхитує середній.

**Свій AI.** Функція отримує гру, номер гравця та параметри рівня і робить дії
через API; завершувати хід не треба:

```js
Slay.AI.custom[1] = (game, me) => {
  for (const t of game.territories()) {
    if (t.owner !== me || t.size < 2) continue;
    for (const from of t.hexes) {
      const h = game.hexes[from];
      if (!h.unit || h.unit.moved) continue;
      const targets = game.legalMoves(from).filter(k => game.hexes[k].owner !== me);
      if (targets.length) game.moveUnit(from, targets[0]);
    }
    const spots = game.buyTargets(t.capital, 1);
    if (spots.length) game.buyUnit(t.capital, 1, spots[0]);
  }
};
```

Корисні методи `Game`: `territories()`, `territoryOf(key)`, `legalMoves(key)`,
`moveUnit(from, to)`, `buyTargets(anchor, level)`, `buyUnit(anchor, level, to)`,
`castleTargets(anchor)`, `buildCastle(anchor, to)`, `defense(key)`,
`economy(territory)`, `borderTargets(territory)`, `stats()`, `serialize()`,
`Game.deserialize(str)`. `anchor` — будь-який гекс потрібної території.

**Гачки.** `Slay.hooks.beforeTurn(game, id)`, `afterTurn(game, id)`,
`onAction(game)`, `onGameOver(game)`.

**Прогін без інтерфейсу.**

```js
const r = Slay.simulate({ players: ['ai','ai','ai','ai'], seed: 7, maxRounds: 300 });
r.winner, r.rounds, r.game.stats()
```

Стан гри — звичайні об'єкти (`Slay.game.hexes`), його можна правити прямо в
консолі, після чого викликати `Slay.game.invalidate(); Slay.refresh()`.
Один і той самий seed дає одну й ту саму карту та ті самі випадкові події.
